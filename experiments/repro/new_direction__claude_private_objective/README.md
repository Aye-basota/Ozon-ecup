## 1. Что сделало лучшее решение сильным

Механизм: LB — точная детерминированная функция файла, поэтому каждый скор есть одно
линейное измерение неизвестного `t = log1p(y)`.

    z_i = log1p(pred_i);  d_ref = z_ref − t;  z = z_ref + Φᵀc
    score_i² = R + 2 c_iᵀp + c_iᵀc_i        (65 уравнений, 59 параметров)
    p_k = ⟨d_ref, φ_k⟩

Общая закономерность (не трюк): **слабые расходящиеся модели дают систему координат,
в которой лидерборд измеряет истину.** χ²/df от p̂ по семействам:
EXP-SIM 21.8, BTYD 12.0, LGBM 11.1, LOGENS 10.3, NAIVE 8.9 (LB 1.88–2.12!) —
против STRONGEST 1.15, DIST 1.30, S1-BEST 1.52, LEVEL 0.0.
Сильнейшие по LB семейства несут меньше сигнала на степень свободы, чем плохие модели.

Оптимальный шаг вдоль направления может быть отрицательным: у `experimental_submission_2`
выравнивание +0.0308 (t = +4.67), оптимальный коэффициент −0.139. Офлайн-гейт вида
«улучшает ли добавление с α ∈ {0…1}» такого не находит — проект и закрыл EXP-SIM.

### 2.1 Спан исчерпан точно

В проекции на пространство всех когда-либо построенных моделей у чемпиона не осталось

**Незадействованная степень свободы — целевая функция.** При фиксированном f = 0.2:

    A_true = f·A_pub + (1−f)·A_priv   ⟹   A_priv = 1.25·A_true − 0.25·A_pub

Геометрия минимизировала E[A_true]. Место считается по A_priv.

## 4. Математическое обоснование

    p_priv = 1.25·p_N − 0.25·p_pub
    E[p_priv | p̂] = 1.25·p̃ − 0.25·p̂
    c_priv = −(1.25·p̃ − 0.25·p̂) = 1.25·c_champ + 0.25·p̂
    E[A_priv(c_champ)] − E[A_priv(c_priv)] = ‖c_priv − c_champ‖² = 0.0625·‖p̂ − p̃‖²

При `p̃ = s·p̂` приватно-оптимальная усадка `s′ = 1.25s − 0.25` — всегда строже.
Для направлений, объявленных шумом (s = 0), `s′ = −0.25`: двигаться против публичного
оптимума. Именно там сосредоточена публичная удача (8 вырожденных направлений несут
57% шума по отчётам проекта).

    ‖p̂‖² = 0.0113332 ; ‖p̃‖² = 0.0054407 ; ‖p̂ − p̃‖² = 0.0024741
    выигрыш = 0.0625 × 0.0024741 = 1.546e−04 MSE = −4.69e−05 RMSLE (private)

`‖p̂ − p̃‖² = ‖P_span d_cur‖²` — тождество: не взятая усадка и есть весь инспанный
остаток, и он равен шумовому полу. Чемпион откалиброван правильно под свою цель;
цель была не та.

Дополнительно: пренебрежённый член `c′(G_P − I)c` добавляет к дисперсии p̂ в медиане
+9% для рабочих направлений и катастрофически много для λ < 1e−5. Это независимо
оправдывает их обнуление и означает, что эффективная κ₂ выше принятой.

## 6. ОДИН рекомендуемый эксперимент

**Перецелить чемпиона с полного теста на приватные 80%.**

    c_new = 1.25·c_champion + 0.25·p̂
    z = z_ref + Φᵀ c_new ;  predict = max(expm1(z), 0)

|---|---|

| SHA256 | `899c5ae7072db952ef08418553e3d0a07c95a85bee9e42c226db32213544dad2` |

| ресурсы | ≈20 с CPU, ноль обучения, один сабмит |

**Цепочка.** Наблюдение: публичный выигрыш −0.0025 обернулся реальным −0.0012; шесть
последних экспериментов дали ноль; остаток чемпиона в спане = 0.98 шумового пола. →
Закономерность: метод исчерпал информацию о публичных 20% и продолжает оптимизировать
по ним, а оценивается по приватным 80%; публичная удача входит в приватный скор с
коэффициентом −0.25. → Гипотеза: `c_priv = 1.25·c_champ + 0.25·p̂`, разрыв =
`0.0625·‖p̂ − p̃‖²`. → Предсказание: public +4.225e−04 (±6.8e−05), private −4.69e−05. →
Эксперимент: отправить файл; публичный скор — прямая проверка предсказания.

**Отличие от уже проверенного.** Это не изменение усадки (простое усиление проверено и
вредит при κ₂ ∈ {1, 1.4}); не новое перевзвешивание внутри спана (оба сеанса геометрии
искали минимум E[A_true]; разложение `A_priv = 1.25·A_true − 0.25·A_pub` не встречается
ни в `reasoning_log.md`, ни в `REASONING_LOG_v3.md`, ни в `SHRINKAGE_CALIBRATION.md`);
не probing (файл — обычная аффинная комбинация уже отправленных сабмитов).

**Главный риск.** Если финал считается по всему тесту, сделка разворачивается и стоит
тех же +4.69e−05. При наличии промежуточного отбора по публичному LB эксперимент
проводить нельзя — публичный скор ухудшится заведомо.
Второй риск: `c_champ` = `0.25·c_v2 + 0.75·(−p̃)` — захеджированная точка, а не строгий
argmin; отображение точно только для argmin. Учтено в таблице устойчивости.

**После сабмита №2 — решает судьбу out-of-span программы:**

    p_v = ( score² − A_анкор − α²·rms(v)² ) / (2α·rms(v))      — точно, α и rms(v) известны

- |p_v| > 0.020 (t > 3): направления вне спана несут реальный сигнал → строить новые, приоритет №1.
- 0.007 < |p_v| < 0.020: уровень среднего существующего направления → реализовать через α*, программу не наращивать.
- |p_v| < 0.007 (t < 1): τ̂ ≈ 0.08 подтверждается и на ортогональном канале → остановить моделирование, зафиксировать кандидат №1.

**Чего не хватает в данных:**
- фолда, календарно совпадающего с тестом (все четыре — сентябрь–октябрь); это структурное, а не вычислительное ограничение;
- канонического OOF для `occ_meta_B`, `occ_raw_X3`, SEQ65, Ridge-стека (нет 80 fold-NPZ и ~9.7 ГБ кэша);
- второй out-of-sample точки для калибровки τ на ортогональных направлениях — её даёт сабмит №2;
- `T = ‖t‖²` по-прежнему не восстановлен, но, вопреки §12 старого лога, не нужен: направление «сжатие к константе» — функция от z, её первые четыре степени свободы на 78–100% внутри спана и уже применены (§3).
