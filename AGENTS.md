# AGENTS — правила для ИИ-агентов

## Перед задачей

- Прочти `STATE.md` целиком. Он короткий (~80 строк), это дёшево.
- `experiments/*.md` и `HISTORY.md` по умолчанию НЕ читай.
  Открывай конкретный `exp_NNN`, только если:
  - повторяешь или развиваешь чужую идею;
  - твоя гипотеза похожа на пункт из «Не повторять» и нужны детали;
  - пишешь итоговую сводку.

## После эксперимента

1. Создай `experiments/exp_NNN_<name>.md` из `experiments/_template.md`.
2. Обнови `STATE.md`: таблица, «Текущий лучший», при провале — строка в «Не повторять».
3. Если в таблице STATE.md стало больше 10 строк — старые перенеси в `HISTORY.md` (новые сверху). Провалы при этом остаются в «Не повторять».

## Жёсткие запреты

- Не трогать `src/validation.py` и `src/config.py` без явного запроса.
- Seed — только из `config.py`.
- Фичи только добавляются новыми колонками, чужие не переписывать.
- Фичи строятся только через `build_features(cutoff_date)`.
- Никаких данных после cutoff в фичах — каждую новую колонку проверяй на лукап.
- Данные не коммитить (`data/`, `submissions/` в .gitignore).
- Не удалять строки из «Не повторять».
- Не превышать лимит STATE.md (~80 строк).

## Стиль

- Simple first: минимум зависимостей, минимум абстракций.
- Код запускается одной командой: `python src/<script>.py`.
