# Ozon e-cup — Ценность пользователей поиска

## О проекте

По дневной истории активности пользователя в Поиске и Каталоге
(запросы, корзины, покупки) предсказываем суммарную стоимость его
заказов за следующие 30 дней. Регрессия, таргет — сумма в рублях.

## Структура

```
├── README.md            — этот файл
├── STATE.md             — текущее состояние, читать перед каждой задачей
├── HISTORY.md           — архив старых экспериментов
├── AGENTS.md            — правила для ИИ-агентов
├── requirements.txt     — зависимости
├── experiments/         — детали экспериментов (exp_NNN.md)
├── src/
│   ├── config.py        — seed, пути, даты cutoff (НЕ трогать без запроса)
│   ├── validation.py    — out-of-time сплит и метрика (НЕ трогать без запроса)
│   ├── features.py      — build_features(cutoff_date) — единый вход фичей
│   ├── train.py         — обучение одной модели
│   ├── predict.py       — сабмит одной модели
│   └── ensemble.py      — объединение моделей в сабмит
├── data/                — данные (не коммитим)
└── submissions/         — сабмиты (не коммитим)
```

## Ветки

- `main` — только через PR.
- `team-a`, `team-b` — по 2 человека, рабочие ветки.

Правила:
- Раз в день подливаем `main` к себе в ветку.
- Фичи только **добавляются новыми колонками**, чужие не переписываем.

## Принципы

1. Единая валидация на всех — только `src/validation.py`.
2. Один пайплайн фичей `build_features(cutoff_date)` для train/val/test.
3. Только out-of-time валидация: никаких случайных сплитов, таргет — следующие 30 дней.
4. Один эксперимент = одно изменение.
5. Результат любого эксперимента записывается, даже провал.

## Быстрый старт

```bash
pip install -r requirements.txt
# положить данные в data/raw/
python src/features.py   # построить фичи
python src/train.py      # обучить и получить CV
```
