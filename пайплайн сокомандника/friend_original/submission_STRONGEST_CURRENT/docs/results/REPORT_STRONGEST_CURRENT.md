## 1. Точная формула ансамбля

```text
z_mix = 0.10·z(S1-CAP) + 0.20·z(S1-UNC) + 0.25·z(S1-DIST)
      + 0.225·z(ETX-AVG3) + 0.225·z(SEQ-AVG3)

ETX-AVG3 = mean(z_ETX-01-S42-DCW, z_ETX-01-S43-DCW, z_ETX-01-S44-DCW)
SEQ-AVG3 = mean(z_SEQ-01,        z_SEQ-C289-S43,    z_SEQ-C289-S44)

pred = expm1(max(z_mix + δ, 0)),  δ = −0.13536,  L* = 2.3293
```

Всё усреднение — **в лог-пространстве** `z = log1p(pred)`; поэтому три веса по
0.075 на сид — это в точности `0.225 ·` лог-среднее сидов, тот же объект, что в OOF.

Команда сборки (одна строка, воспроизводимо):

```text
ALPHA=0.5 OUT=submission_STRONGEST_CURRENT.csv bash research/strategies/results/ETX2/make_submission.sh
```

## 2. Sequence-рецепт

**ETX**: `STRATEGY_13` вариант B, архитектура `ETX-01` не менялась ни в одной оси
(`d_model` 128, 5 блоков, 8 голов, `head_dim` 16, GEGLU 384, dropout 0.1,
`n_tok` 192, batch 512, chunk 128, lr 1.5e-3, wd 1e-2, 4 эпохи, warmup 500).
Сиды 42/43/44, по 4 фолда + тестовая модель на 29 cutoff'ах коридора.

**Политика теста `DCW`** — `--depth-clip 289` И приведение статик-контекста
query-токена в обученный диапазон:

* `depth` = 289 вместо календарных 365 (обучающие cutoff'ы дают 93..289);
* день недели cutoff'а = четверг вместо пятницы (все 29 обучающих cutoff'ов и все
  4 фолда — четверги, то есть в обучении этот вход КОНСТАНТА).

Событийные токены не трогаются: их `age`, `gap`, `dow` остаются календарными.
Обоснование и замеры на размеченных фолдах — `depth_dow_evidence.md`; коротко:
согласованный статик лучше на 8 парах из 8 (три независимых чекпойнта), а сдвиг
дня недели на +1 стоит +0.0026…+0.0087 RMSLE.

## 6. Ожидаемый LB

Перенос локальной дельты SEQ-члена на LB измерен и равен **0.57** (`exp_025`:
обещано −0.00106 wCV, получено −0.00060 LB).

| | значение |
|---|---|
| честный LOFO к `SEQ-01-MIX` | **−0.00092**, 4/4 |
| ожидание LB при переносе 0.57 | 1.6501764 − 0.00052 = **≈ 1.64966** |
| при переносе 1.0 (как у табличной части, `exp_016`) | ≈ 1.64926 |
| при переносе 0.3 | ≈ 1.64990 |
| **рабочий диапазон** | **1.6493 … 1.6500** |
| парная SE public | 0.00025 → ожидаемый выигрыш ≈ **2 SE** |
| инкремент к готовому `SEQAVG3-CLIP-MIX` | LOFO −0.00037 → LB ≈ −0.00021 |
| **ФАКТ (отправлено 2026-08-20)** | **1.6496571**, δ = **−0.0005193**, **2.1 парной SE** |
| фактический перенос wCV→LB | **0.564** против ожидавшихся 0.57 |
| промах прогноза | **3e-6** (прогноз 1.64966) |

Прогноз попал в центр диапазона: перенос 0.57, измеренный в `exp_025` на одном
сабмите и подтверждённый косвенно в `exp_035`, **воспроизвёлся третий раз и
теперь опирается на две независимые точки LB**. Это отдельный результат: шкала
«локальная дельта → дельта LB» у sequence-члена перестала быть догадкой.

**Уровень ~1.645 нереалистичен от этой ветки.** Чтобы взять 1.645, нужна дельта
LB −0.0052, то есть при переносе 0.57 — честный LOFO **−0.0091**, в десять раз
больше достигнутого. Ни один член проекта такого порядка не давал: рекорд слота
за всю историю — как раз эти −0.00092. 1.645 закрывается не весами и не ETX,
а другим источником сигнала.

## 7. Вердикт: **SEND** — исполнено, LB **1.6496571**

Все критерии выбора выполнены:

1. честный LOFO **−0.00092**, **4/4 фолда, включая 10-16** — лучший член слота
   за историю проекта (прежний рекорд −0.00061 у `SEQ-D3A-AVG3`);
2. нового train→test сдвига нет: пара членов 0.78× (полоса проекта 0.63–1.11×),
   готовый кандидат против чемпиона 0.94×, по полосам активности максимум 1.07;
3. `S1-CAP` сохранён с весом 0.10;
4. только после этого — абсолютный локальный минимум (wCV 1.74751, лучший из всех
   собранных смесей проекта).

> **Почему именно этот файл сейчас имеет максимальную ожидаемую вероятность пробить
> 1.650176:** он единственный несёт член слота с честным LOFO −0.00092 на 4/4 фолда
> (в 1.7 раза больше прежнего рекорда −0.00055 у уже готового `SEQAVG3-CLIP-MIX`)
> и при этом расходится с отправленным чемпионом на тесте РОВНО так же, как на
> валидации (0.94× против 0.92× у безопасного варианта), то есть покупает
> дополнительную дельту, не покупая нового режима; при измеренном переносе 0.57 это
> ≈1.64966, около двух парных SE — знак уверенный, величина нет, а уровень ~1.645
> от этой ветки недостижим примерно в десять раз.

**Что подтвердилось после отправки.** Дельта LB −0.0005193 против предсказанных
−0.00052; фактический перенос 0.564 против ожидавшихся 0.57. То есть выигрыш
пришёл ровно из того члена и ровно того размера, который померил честный LOFO, —
и это второй независимый замер коэффициента переноса у sequence-члена (первый —
`exp_025`). Прогноз попал в центр заявленного диапазона 1.6493…1.6500.

**Резервный вариант, оставшийся неиспользованным:**
`submissions/submission_SEQAVG3_clip289_mix.csv` (LOFO −0.00055, 4/4, ожидание
