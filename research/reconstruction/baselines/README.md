# Baselines

`chronology.csv/jsonl` records every explicit baseline/reference recipe in first
seen order within its own research line. `chronology.md` is the readable view.

The table deliberately retains textual near-duplicates. A shared name does not
prove shared folds, train coverage, calibration, prediction source, or metric.
No baseline is propagated across namespaces unless concrete lineage evidence
does so.
