# Evidence

This directory contains forensic audits, small machine-result copies, linked-
worktree manifests, and normalized extraction JSONL. Primary report snapshots
live under `../experiments/`; large predictions/checkpoints/data remain in place
and are referenced by checksum manifests.

Read `SOURCE_POLICY.md` before using any result. In particular, old state,
instruction, roadmap, and master-summary files were never fact sources.

`secondary_summary_conflicts.jsonl` and its audit document record 22 claims
that disagree with or overgeneralize canonical evidence; all are explicitly
secondary-only and are not used to reconstruct experiment FACTS.
