# Leaderboard evidence

`chronology.csv/jsonl` contains only repository-internal score-to-existing-file
links that survived artifact and recipe checks. “Verified” here means strong
repository-internal linkage; it does not mean independent competition-platform
confirmation. No platform export or screenshot survives.

`report_only_claims.csv/jsonl` preserves all remaining report/script score
claims, including missing files, ambiguous file binding, and the strongly
reconstructed `latest.csv` whose score event itself is not SHA-bound.

Local CV, ensemble wCV, and LB are separate fields and are never pooled.
