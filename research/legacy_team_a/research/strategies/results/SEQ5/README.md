# SEQ5 — EXP-030 `SEQ-D3A`: depth curriculum

Артефакты прогона EXP-030. Полное описание — `experiments/exp_030_seq_depth_curriculum.md`.

## Что здесь

| файл | что |
|---|---|
| `run.sh` | 7 фолдовых прогонов: BASE ×3 + D3A ×4, seed 42 (~7.9 ч) |
| `diag.sh` | `depth` / `crossdepth` / `availprobe` на сохранённых весах (inference-only) |
| `analyze.py` | пофолдовая сводка, wCV, AUC, сегменты, `Var(Δ)`, корреляции |
| `depth_table.py` | сравнение BASE и D3A по трём диагностикам глубины |
| `folds.csv` | пофолдовые метрики обоих вариантов |
| `segments.csv` | 10 сегментов × 4 фолда × 2 варианта |
| `depth.csv`, `crossdepth.csv`, `availprobe.csv` | сводки диагностики глубины |
| `VALIDATION_MAIN_AUDIT.md` | отдельная проверка схемы валидации из `origin/main` |

Главное — не wCV, а глубина: cross-depth gain +77 дней вырос с −0.00155 до
−0.00368, внутренний оптимум глубины исчез (лучшая глубина стала максимальной),
`availprobe` остался +0.0059. То есть механизм, ради которого ставился
эксперимент, работает, а `exp_029` он не повторяет.

## Замечания к чтению чисел

- BASE обязателен пофолдовый и в том же режиме: локальный eager систематически
  горячее исторического A10-прогона `exp_025` (10-16: 1.74808 против 1.74704).
- BASE фолда 10-16 — тот же прогон, что `SEQ-03A-BASE-S42-V1016` в `exp_029`,
  скопированный под именем `SEQ-D3A-BASE-S42-V1016`, а не переобученный.
- Один сид не разрешает ΔwCV: seed std TCN по wCV = 0.00250, наблюдённая
  дельта −0.00077. Решение по приёму без 3 сидов принимать нельзя.
