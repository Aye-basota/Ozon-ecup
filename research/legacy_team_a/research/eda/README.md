# research/eda — воспроизведение исследования

Скрипты запускаются из этой директории и читают `data/raw/train.parquet`
и `data/raw/sample_submit.csv` (не коммитятся, см. `.gitignore`).

```bash
pip install polars lightgbm scikit-learn psutil pyarrow
cd research/eda
python -u e02_structure.py
```

Логи прогонов, на которые ссылаются документы, лежат в `logs/`.

## Что какой скрипт устанавливает

| скрипт | результат | где используется |
|--------|-----------|------------------|
| `fe.py` | общий feature-билдер: `panel_users(T, n_blocks)`, `build_features(T, users)`, `target(T, users)`, `make_xy(T)` | все остальные |
| `e01_schema.py` | схема parquet, 30 631 006 строк × 18 колонок, `created_by: Polars` | `eda_findings.md` §1 |
| `e02_structure.py` | колоночная алгебра (6 из 18 колонок — точные производные, 0 нарушений); 14.85% полностью нулевых строк | §1.3, §6.1 |
| `e03_submit_forensics.py` | **`sample_submit.predict` = Σ gmv за 2026-01-15..02-13, 100.00% совпадений** | §2 |
| `e04_hidden_structure.py` | `user_id` неинформативен (все corr < 0.002); когорты; дневной ряд; отложенная атрибуция 0.54% | §4.1, §5.1 |
| `e05_selection_seasonality.py` | RMSLE-якоря наивных предикторов; опровержение поправки ×1.16 | §5.4, §7.1 |
| `e06_panel_logseason.py` | `min(last_d)=2026-01-15`, `max(first_d)=2025-12-15`; отравление поздних cutoff'ов | §3.2 |
| `e07_blocks_anchor.py` | **3-блочное правило панели** (100.000% / 100.000% / 100.000% / 93.26%); якоря уровня теста | §3.1, §5.3, §6.2 |
| `e08_baseline.py` | цена отравления (1.77114 против 1.82485); панель 3-блок против 1-блок; важность признаков | §3.3, §3.4, §7.2 |
| `e09a_calib.py` | якорный (delta) таргет; смещение −0.0865 (32 дн) и −0.1534 (62 дн) | `strategy_1.md` §7.2 |
| `e09b_season.py` | сезонность на фиксированной панели: YoY-аналог `dm = +0.1659` — максимум года; дневные календарные факторы | §5.2 |
| `e12_calib_adv.py` | анатомия ошибки; **adversarial AUC 0.9930 против теста**; уровень прогноза на тесте 2.6465 | §7.3, §7.4 |
| `e13_capped.py` | усечение истории до `L = 180`: **AUC 0.993 → 0.70**, смещение втрое ниже, уровень 2.5362 | §7.4 |
| `e14_struct_seq.py` | структурная модель Poisson × LogNormal (первый прогон; секция C падает — см. `e15`) | `strategy_2.md` §1 |
| `e15_seq.py` | sequence-проба (−0.00024), структурная 1.77459, корреляции остатков, блендинг | §10 |

## Известные ограничения

* `e14_struct_seq.py` падает в секции C: на раннем cutoff'е доступно меньше недель
  (96 колонок против 104). Это сам по себе пример артефакта глубины истории (§7.4).
  Исправленная версия — `e15_seq.py` (фиксированное число недель).
* `e09a_calib.py` и `e12_calib_adv.py` требуют ~7–10 ГБ RAM. При нехватке
  уменьшить число cutoff'ов в списке `CUTS`.
* Калибровочные параметры структурной модели в `e14`/`e15` подбираются
  **на валидации** — это верхняя оценка эффекта, а не честный результат.
