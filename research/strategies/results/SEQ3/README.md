# SEQ3 — почему `SEQAVG3-MIX` провалился на LB и какая политика глубины верна

Отчёт `exp_027`. Всё inference-only: ни одна модель не обучалась.

## Что тут лежит

| файл | что считает |
|---|---|
| `decompose_test.py` | этап 1: разложение тестового прогноза по трём осям (усреднение / веса / глубина) |
| `stress.py` | этапы 2-3: кросс-фолдовая кривая глубины при экстраполяции +49..+77 и усадка `α` |
| `lofo.py` | этап 4: честный LOFO семейств смеси на существующих OOF |
| `test_axes.csv`, `test_segments.csv` | результат этапа 1 |
| `stress_curve.csv`, `stress_summary.csv` | результат этапа 2 |
| `alpha_curve.csv`, `alpha_lopo.csv`, `gating.csv` | результат этапа 3 |
| `lofo_families.csv`, `lofo_weights.csv` | результат этапа 4 |
| `seed_common_depth.csv` | проверка допущения «сдвиг от глубины одинаков у сидов» |

## Воспроизведение

```bash
bash research/strategies/results/SEQ3/run.sh
```

Требуется только то, что уже лежит в `artifacts/`: чекпойнты фолдов
`model_SEQ-01-S4{2,3,4}-V*.pt` (`exp_026`), тестовые прогнозы `ztest_*`,
OOF `oof_*`. Полный прогон — около 40 минут на RTX 4060 Ti.

## Главное в одной таблице

Три оси, на которые распадается переход `SEQ-01-MIX` -> `SEQAVG3-MIX`
(`Var(Δz)` на тестовом прогнозе, уровень снят якорем):

| ось | `Var(Δz)` | ожидаемый вред, если Δ — чистый шум |
|---|---|---|
| усреднение сидов | 0.00128 | +0.00039 |
| веса смеси | 0.00097 | +0.00030 |
| **политика глубины** | **0.01819** | **+0.00551** |

Факт LB: **+0.0051372**. Первые две оси вместе не дотягивают и до 15% этого числа.

Механизм — не сама глубина, а канал `avail`: у всех 29 обучающих cutoff'ов и всех
4 фолдов в окне не меньше 76 позиций с `avail = 0`, а на тесте при полной глубине
их **ровно ноль**. Цена одного этого бита при неизменных данных — **+0.0034…+0.0044**
калиброванного RMSLE на 5 конфигурациях (`availprobe`).
