# STRATEGY_05 — ёмкость и дисперсия оценщика: итог вариантов A + B

- **Дата:** 2026-08-12
- **Карточки:** `experiments/exp_017_capacity_curve.md`, `experiments/exp_018_seed_average.md`
- **Журнал:** строки `S1-ROUNDS`, `S1-SEEDAVG5` в `experiments/log.csv`
- **Разборы:** [`variant_A.md`](variant_A.md), [`variant_B.md`](variant_B.md)
- **Стоимость:** 28 мин (A) + 32 мин (B) = **1 час** против 3 ч по оценке стратегии
- **Опорные точки:** `S1-E10` (одиночная `direct`, wCV **1.75170**),
  `S1-DIST-MIX` (боевая смесь, wCV **1.74948**)

## Результат A — кривая по раундам

Снята полная кривая `RMSLE_cal(rounds)` на 4 фолдах, 16 точек от 25 до 1600.

**Посылка стратегии опровергнута со знаком.** 600 раундов — не недобор, а
**переобучение**: минимум лежит на 200 (wCV 1.75103, −0.00067 к `S1-E10`,
4 фолда из 4), плато 200–300, и вправо кривая монотонно ухудшается — 1600 раундов
стоят **+0.00287 wCV**, больше, чем весь выигрыш `E0` (−0.00145) и смеси
с головой распределения (−0.00071) вместе взятых. Рекомендация
`strategy_1_results.md` §9 п.2 («600 при 6 млн строк почти наверняка недобор»)
отправила бы модель ровно в эту сторону.

Оптимум растёт с объёмом обучающей выборки монотонно по всем фолдам:
**150 / 200 / 250 / 300 раундов при 18 / 20 / 22 / 24 обучающих cutoff'ах**,
ровно +50 раундов на два cutoff'а. Дно при этом плоское (0.00003 между 200 и 300
на фолде 10-16 при парной SE фолда 0.00012), поэтому разрешено «не 600»,
но не точная позиция argmin внутри 150–300.

## Результат B — дисперсия по сидам

Пять сидов (42–46) боевой конфигурации при 300 раундах.

| величина | значение |
|---|---|
| разброс `wCV` по сидам | std **0.00010**, range **0.00023** |
| `Var(z_i − z_j)`, среднее по 10 парам | **0.00712** ⇒ `σ² = 0.00356` на сид |
| corr остатков между сидами | **0.99885** |
| выигрыш усреднения: 2 / 3 / 5 сидов | −0.00048 / **−0.00064** / −0.00077 |
| предел `k → ∞` | −0.00102 |

Кривая усреднения монотонна, выходит на плато после 3 сидов и совпадает
с теорией `MSE_k = M + σ²/k` **с точностью 0.00004 на всех k** — то есть
дисперсия оценщика описана полностью и снимается ровно так, как обязана.

**Критерий закрытия направления («разброс `wCV` по сидам < 0.0003 ⇒ усреднение
бесполезно») формально сработал и отвергнут замером в том же эксперименте:**
разброс 0.00023, а усреднение дало −0.00071. Разброс *скора* мал потому, что
скор уже усредняет 190 тыс. строк; усреднение снимает дисперсию *предсказаний*.
Правильная статистика — `Var(z_i − z_j)`, а не std(`wCV`).

## Лучший найденный config

```
direct, 227 признаков S1-E10 (--L 0 --norm-long --min-history 90),
--train-blocks 1 --cutoffs all (шаг 7), panel_blocks 3, LGB_PARAMS из config.py,
rounds = 300 (вместо 600), усреднение по 3 сидам в лог-пространстве
```

| конфигурация | wCV | Δ к `S1-E10` | фолдов лучше |
|---|---|---|---|
| `S1-E10` — боевая одиночная `direct` (600 раундов, сид 42) | 1.75170 | — | — |
| 300 раундов, сид 42 | 1.75108 | −0.00062 | 4/4 |
| **300 раундов, среднее 3 сидов** | **1.75046** | **−0.00124** | **4/4** |
| 300 раундов, среднее 5 сидов | 1.75037 | −0.00133 | 4/4 |
| `S1-DIST-MIX` — сильнейшее решение проекта (смесь) | 1.74948 | — | — |

Дельты складываются арифметически по построению (B мерился от точки A).
Содержательно здесь другое: снижение ёмкости **не съело** дисперсию оценщика
заранее — усреднение при 300 раундах дало полный теоретический эффект.
Одиночная `direct` после A + B по-прежнему уступает боевой смеси 0.00089 wCV —
обе ручки применяются **ко всем членам смеси**, а не заменяют её.

## Стоит ли увеличивать capacity

**Нет — наоборот, её надо снижать.** Это самый уверенный вывод обоих вариантов:
300 раундов лучше 600 на 4 фолдах из 4, всё, что правее 600, хуже него на 4 из 4,
и кривая монотонна вправо на всём диапазоне до 1600.

Практическая форма правила: **число раундов — функция объёма обучающей выборки**,
и переносить его между конфигурациями с разным числом cutoff'ов нельзя. Именно
это и произошло с числом 600: оно приехало с бейзлайна `S1-B0` (3 cutoff'а,
0.63 млн строк) на плотную сетку (24 cutoff'а, 4.96 млн) без пересмотра — и
оказалось переобучением. Измеренная зависимость: **+50 раундов на два cutoff'а**
(экстраполяция на боевые 29 cutoff'ов даёт ≈425, локально не проверяема).

`learning_rate`, `num_leaves`, `min_data_in_leaf`, `feature_fraction` не
трогались и остаются вне области стратегии (`EXP-MIN`, LB +0.01614).

## Сколько сидов использовать дальше

**Три.** Предельный выигрыш шага быстро садится: 1→2 даёт 0.00048, 2→3 — 0.00016,
3→4 — 0.00008, 4→5 — 0.00005. Три сида забирают **83 % того, что дают пять**
(и 63 % предела `k → ∞`), при линейном росте стоимости.

Цена при 300 раундах: **24 минуты** на 3-сидовый `direct` (4 фолда, два процесса
по 6 потоков) против 8 минут на одиночный. Для `dist` то же обойдётся в ~2 часа —
вариант C стратегии остаётся неисполненным и теперь оправдан (см. ниже).

Второе применение сидов, не менее важное: **3-сидовое среднее как измерительный
инструмент**. std(`wCV`) у него 0.00004 против 0.00010 у одиночного сида, то есть
дельты порядка 0.0003–0.0010 становятся читаемыми, а на одиночных сидах — нет.

## Какой Δ wCV теперь считать содержательным

Три шкалы шума, от мелкой к крупной:

| шкала | величина | источник |
|---|---|---|
| парный шум метрики на OOF | 0.00006 | `exp_016` §8 |
| **шум сида**: std(`wCV`) одиночного прогона | **0.00010**; разница двух независимых одиночных прогонов — 0.00014 (1σ) | `exp_018` |
| систематика неизмеримой оси `train→test` | **≈0.0005** | `exp_016` §8 |

Рабочее правило после этого эксперимента:

* **Δ < 0.0003 на одиночных сидах — не результат.** Это ≤2σ разницы двух
  независимых прогонов одной и той же конфигурации.
* **0.0003–0.0010 — измеримо только на 3-сидовых средних** (их σ вдвое меньше);
  на одиночных сидах такие дельты неотличимы от жребия.
* **Порог `exp_016` §6 остаётся в силе без изменений**: `≤ −0.0020` принять,
  `−0.0020…−0.0005` в разработку, `> −0.0005` отвергнуть. Шум сидов его не
  двигает — он задан систематикой неизмеримой оси (0.0005), которая крупнее.
* **Исключение, подтверждённое вариантом B:** для изменений, которые не трогают
  ось `train→test` и знак которых известен заранее (усреднение сидов, число
  раундов), нижняя граница — шум сидов, а не 0.0005. Такие изменения принимаются
  от 0.0005 и в сабмит идут только вместе с чем-то ещё.

**Отдельно — пол разнообразия.** Два сида одной конфигурации не несут друг о
друге никакой информации, поэтому `Var(Δ) = 0.00712` есть **ноль разнообразия**,
а corr остатков 0.99885 — потолок «похожести». В этой шкале:
`S1-DIST` против `S1-E10` — ×1.85 от пола (структурная часть 46 %),
`S1-E11` против `S1-DIST` — ×1.50 (33 %). **От трети до половины «разнообразия»
боевой смеси — шум сидов, а не разные функции.**

## Итоговый статус: **ACCEPT**

Обе ручки приняты в разработку; обе — гигиена базовой модели, применяются ко
всем членам смеси сразу, риска на неизмеримой оси не несут и переносятся на LB
один к одному (`exp_016` §8, класс «внутри измеримого пространства»).
Ни одна по отдельности не проходит порог сабмита −0.0020 — но сабмитов и
не осталось, а вместе они дают −0.00133 на одиночной модели.

Варианты **C** (та же кривая для `dist`) и **D** (сиды в смеси при фиксированных
весах) — **CONTINUE**, не выполнялись: они выходят за рамки задачи A + B.
Оба теперь оправданы: C — потому что `dist` тоже могла приехать на чужом числе
раундов (её единственный замер в `exp_014` намекал на оптимум 150–200 при
заданных 250), D — потому что эффект B на одиночной модели подтверждён.

## Влияние на остальной бэклог (`STRATEGIES_INDEX.md`)

1. **Все члены боевой смеси обучены на 600 раундах** (`S1-E02`, `S1-E10`,
   `S1-E03a`) — то есть все переобучены одним и тем же механизмом. Самое дешёвое
   продолжение из всего бэклога: пересобрать смесь из членов на их собственном
   числе раундов, **не трогая веса** (`exp_016` §6). Это вариант D + перенос A.
2. **`STRATEGY_02` (дизайн обучающей выборки) — прямое взаимодействие.**
   `train_blocks = 0` и «плотность при равном объёме» **меняют объём обучающей
   выборки**, а оптимум по раундам от него зависит (+50 на 2 cutoff'а). Сравнение
   при фиксированных 600 (или фиксированных 300) раундах смешает два эффекта.
   Требование: в каждом плече `02` снимать мини-кривую по раундам (3–4 точки,
   один прогон с `--snap`).
3. **`STRATEGY_01` (вторая ось валидации)** — то же: фолды с искусственным
   разрывом `G` имеют меньше обучающих cutoff'ов, и разница по `G` частично
   окажется разницей по ёмкости. Число cutoff'ов в плечах надо выравнивать —
   что стратегия и предписывает, теперь есть количественная причина.
4. **`STRATEGY_03` (головы `p(n)`, `p(n)×m(n,v)`), ожидание −0.0002…−0.0008** и
   **`STRATEGY_08` (личное время), −0.0003…−0.0015** — попадают целиком в зону,
   где одиночный сид ничего не разрешает. **Мерить их на 3-сидовых средних,
   иначе результат нечитаем.** Заявленная ценность `03` — разнообразие
   (corr остатков 0.9850) — устояла: это заметно ниже пола 0.99885.
5. **`STRATEGY_11` (Ridge/блочные, corr 0.9799)** — тоже устояла и остаётся
   единственным кандидатом с корреляцией, явно ниже пола сидов.
6. **`STRATEGY_06` (мультигоризонт) и `STRATEGY_07` (CatBoost)**: их вклад
   заявлен через разнообразие, и оценивать его теперь надо не по `Var(Δ)`
   как есть, а по `Var(Δ) − 0.00712`.
7. **`STRATEGY_10` / `13` (HDN, ETX)**: у нейросетей дисперсия оценщика заведомо
   больше, чем измеренные здесь 0.00356 у LightGBM, и `strategy_NN_1.md` §4.4
   уже предписывает усреднение по сидам. Теперь у этого предписания есть
   табличный ориентир: одиночный прогон сети без усреднения нельзя сравнивать
   с усреднённым бустингом — разница будет в пользу бустинга по построению.
8. **Правило остановки волн 1–7 («меньше −0.002 суммарно — прекращать»)**:
   вклад `S_05` в этот счёт — **−0.00133 на одиночной `direct`**, перенос
   на смесь не измерен (вариант D).
